Small rounded label/status pill — use for tags like «Запись открыта», age groups, or status.

```jsx
<Badge color="success" variant="soft">Есть места</Badge>
<Badge color="primary" variant="solid" size="sm">Новое</Badge>
```

Colours: `primary` `secondary` `accent` `sun` `success` `info` `neutral`. `variant`: `soft` (tint, default) or `solid`. Sizes `sm`/`md`/`lg`.
