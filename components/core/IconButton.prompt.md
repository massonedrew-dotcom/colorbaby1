Circular icon-only button — use for nav arrows, social links, phone/Telegram actions.

```jsx
<IconButton icon={<i data-lucide="send"></i>} variant="primary" label="Telegram" />
```

Variants: `primary` `soft` (default) `surface` `ghost`. Sizes `sm`(36) `md`(44) `lg`(54). Always pass `label` for accessibility.
