Programme/feature tile — colour icon chip + title + text. Use in "наши занятия" grids.

```jsx
<FeatureCard icon={<i data-lucide="languages"></i>} title="Английский" color="sky">
  Живые занятия с малых лет.
</FeatureCard>
```

`color` themes the round chip (`pink` `orange` `sky` `mint` `purple` `sun`). Map programme categories to the `--cat-*` palette for consistency.
