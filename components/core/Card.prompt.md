Rounded surface container — wraps any grouped content (panels, tiles, list items).

```jsx
<Card tint="pink" hover pad="lg">
  <h3>Развивающие игры</h3>
  <p>Каждый день — что-то новое.</p>
</Card>
```

Props: `tint` (pastel fill), `radius`, `pad`, `hover` (lift), `glow` (coloured shadow), `bordered`. Default is a white surface with a soft warm shadow.
